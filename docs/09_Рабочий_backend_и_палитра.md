# Cursor: рабочая серверная версия и палитра

> Историческое состояние. Актуальная серверная версия описана в [документе 10](10_Backend_PostgreSQL_и_запуск.md).

Эта версия заменяет прежний статус «backend не реализован» в документах 05–08. Всё остаётся в ветке codex/post-meeting-survey, без коммита и публикации.

## Запуск

В корне проекта: `npm run dev`. Это теперь FastAPI, который раздаёт и интерфейс, и API на localhost:4173. Python-окружение уже установлено на компьютере Эдема. На другом компьютере один раз:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
npm run dev
```

Первый запуск предлагает создать администратора. Логин и пароль выбирает сам пользователь. Открытой регистрации нет: следующие учётные записи создаёт администратор в «Команда». Приложение слушает только 127.0.0.1. Это локальный сервер для разработки и проверки командой, пока без публичного размещения.

## Что работает

- FastAPI и SQLite, файл `.data/cursor.sqlite3`. Карта сохраняется на диске, переживает перезапуск процесса и читается другими сессиями этого сервера. localStorage не является источником серверной карты.
- SQLite хранит users, sessions, workspace, audit. Снимок карты хранится как JSON с номером ревизии. Это первый адаптер под существующий MVP; нормализованной PostgreSQL-схемы пока нет.
- Вход и выход, пароль с солью и scrypt, серверные сессии на восемь часов. В базе хранится хеш токена; cookie HttpOnly и SameSite=Strict. Secure включается переменной CURSOR_SECURE_COOKIE=1 при будущем HTTPS-размещении.
- Роли reader/editor/admin: просмотр, редактирование, управление командой. Все активные сотрудники этой одной команды видят всех её клиентов; разрешений по отдельным клиентам пока нет.
- Администратор создаёт пользователей и отключает доступ вместе с отзывом сессий. Можно посмотреть последние 50 действий в журнале. Это технический аудит сохранений, не история изменения каждого поля.
- CSRF для записывающих запросов, проверки Origin/Host, ограничение попыток входа, проверка структуры, ID, оценок, связей и границ клиентов, ограничение размера карты. Закрыта раздача базы, env, Git и Python-кода.
- Оптимистическая блокировка: устаревшая ревизия получает 409 вместо перезаписи чужой карты. Ошибка показана в интерфейсе; запись останавливается и предлагается скачать несохранённый JSON. Автоматического слияния изменений пока нет.
- Перед выходом/перезагрузкой интерфейс предупреждает о несохранённых данных. Сброс примера в серверной версии затрагивает общую карту и явно обозначен в подтверждении. Делать его только на демонстрационных данных.

Данные прежнего браузерного прототипа автоматически не переносятся. Старый режим доступен отдельно через `npm run dev:demo`; он нужен для существующих frontend E2E и статического демо. На GitHub Pages работает только этот режим, Python API там не запускается.

## Визуальные изменения

Применены исходные цвета: #FE982C, #2F6FED, #38761D, #980000, #14213D. Цвета имеют назначение: влияние — синий, поддержка — зелёный, конфликт/риск — красный. Чёрные/тёмные обводки, жёсткие тени, контрастные бейджи и цветные области отделов возвращают характер исходной системы.

Loader: оранжевый фон, крупные глаза, движение взгляда, моргание и плавающие цветные формы. Кнопка «Маскот» открывает просмотр без искусственного замедления настоящей загрузки. В интерфейсе добавлены переходы кнопок, выделение карточки и пульсация выбранной курсором связи без изменения её типа. Reduced motion отключает движение. Появились отдельный экран входа и панель управления командой.

## Проверки

`npm test` — бизнес-логика frontend. `npm run test:backend` — изолированные временные базы и FastAPI TestClient: доступ, сессии, CSRF, некорректные типы, межклиентские связи, ревизии, хранение после повторного создания приложения, роли, отзыв доступа и закрытые файлы. 31 JavaScript-тест и 9 серверных тестов прошли. Восемь общих браузерных сценариев также выполнены через CUA на настоящем API с отдельной тестовой базой. Проверены создание тестового администратора и пользователя через интерфейс. Основная база пользователя и его учётные записи для QA не создавались.

## До общего пилота

Нужны размещение и HTTPS, нормализованная PostgreSQL-схема, доступ по клиентам, процесс смены и восстановления пароля, резервное копирование с проверкой восстановления и проверка нагрузки. Сейчас это реально работающий локальный backend, а не законченный production-сервис.

Основания: [FastAPI testing](https://fastapi.tiangolo.com/tutorial/testing/), [SQLite transactions](https://docs.python.org/3/library/sqlite3.html).

## Исправление перерисовки и управление холстом

Полная замена root.innerHTML заменена на точечное обновление DOM через morphdom (MIT, исходник и лицензия в src/vendor). Сохраняются узлы холста, поиск, фокус, раскрытые секции и прокрутка. Убраны повторные анимации всей карты и сдвиги при hover; открытие форм и маскот сохраняют своё движение.

Добавлены режим холста, панорамирование за фон, пробел/«Двигать», масштаб вокруг указателя, вписывание и переход к контакту. Вокруг карты есть дополнительное пространство для движения. Перетаскивание обновляет геометрию по requestAnimationFrame и сохраняет положение после завершения жеста. Проверка геометрии подписей исключает перекрытие подписей и карточек. В тесных коридорах подпись пропускается, но связь остаётся доступной с мыши и клавиатуры.

Карточка контакта получила нейтральные текстовые метки без капсул и отдельную прокрутку содержимого. Проверены DOM-идентичность, фокус, курсор ввода, камера, жесты и размещение подписей. База и схема API в этой итерации не менялись.
