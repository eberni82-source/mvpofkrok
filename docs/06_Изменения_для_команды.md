# Изменения для команды

Актуальная серверная реализация и последняя палитра описаны в [документе 09](09_Рабочий_backend_и_палитра.md). Ниже сохранён контекст предыдущих итераций.

## Как объяснить Эрнесту

Доработка сохраняет исходный buildless HTML/CSS/JS и локальный адаптер данных. Фреймворк и backend не добавлялись. В этой ветке собраны рабочий опрос после встречи, режимы карты, изолированный черновик песочницы, бренд Cursor и проверяемые пользовательские сценарии. Все файлы остаются в текущем репозитории; коммит и отправку выполняет Эдем после просмотра.

## Что изменилось в последней итерации

| Участок | Изменение | Зачем |
| --- | --- | --- |
| Бренд | Cursor, глаза из CSS, SVG favicon | Общий характер продукта и loader |
| Загрузка | Отдельный boot-модуль, глаза ищут, ошибка с повтором | Понятное состояние запуска без искусственной задержки |
| Кнопки | Округлые контролы, сегментированные режимы, оранжевое основное действие | Ясный текущий режим и главное действие |
| Тексты | Короткие названия, дополнительные сведения раскрываются | Карта занимает внимание вместо инструкций |
| Связи | Маршрут по свободным коридорам, округлённые повороты, направление и широкая область выбора | Линии не проходят через промежуточные карточки |
| Клавиатура | Фокус связей, Tab/Enter, удержание фокуса в форме | Основные действия доступны без мыши |
| Сброс примера | Подтверждение и отмена внутри приложения | Правки удаляются только после явного действия |
| Движение | Моргание, взгляд, появление форм и уведомлений, hover | Аккуратная обратная связь; reduced motion отключает анимацию |
| Экспорт | Отдельный модуль CSV и нейтрализация формул | Защита при открытии пользовательских значений в таблицах |
| Локальный сервер | Loopback, allowlist файлов, запрет .git/env, Host и методов записи, CSP | Раньше сервер мог отдавать служебные файлы из корня |
| Тесты | Проверки маршрутов/экспорта/сервера, сценарии Playwright | Воспроизводимая приёмка основных функций |

Если карточки наложены друг на друга и путь невозможен, связь не рисуется через человека: появляется предложение раздвинуть карточки. Короткие связи не получают плашку, закрывающую стрелку. В режиме влияния посторонние связи приглушены. Для очень больших графов нужна следующая итерация маршрутизации и виртуализации; текущая проверка выполнена на наборе MVP.

## Где искать код

`src/main.js` — действия и экран. `src/cursor.css` — новые компоненты, состояния и motion. `src/mascot.js` — глаза. `src/boot.js` — загрузка/ошибка. `src/graph/curves.js` — маршрутизация (имя функции bezierFor оставлено для совместимости). `src/survey.js` — опрос. `src/export.js` — CSV. `scripts/dev-server.mjs` — безопасная раздача файлов. Серверные решения описаны в `05_Сервер_доступ_и_база.md`.

## Что проверить самому

Запустить `npm run dev` в VS Code и открыть адрес из терминала. Переключить режимы, выбрать человека, открыть связь нажатием или Tab/Enter. Записать встречу, перезагрузить страницу, проверить автора и ответы. В песочнице удалить связь, выйти и убедиться, что исходная карта сохранилась. Скачать CSV. Проверить узкий экран.

`npm test` запускает модульные проверки. Для E2E один раз выполнить `npm install` и `npx playwright install chromium`, затем `npm run test:e2e`. Команда поднимает отдельный сервер на 4301 и запускает девять сценариев в независимых браузерных контекстах. `npm run test:e2e:ui` открывает режим просмотра тестов.

Те же восемь общих сценариев из `tests/e2e/scenarios.mjs` были выполнены через подключённый CUA-браузер; узкий экран и форма также проверены в браузере. Автоматическая эмуляция reduced motion остаётся отдельным девятым сценарием CLI. Запуск CLI-runner в этой сессии проверен обнаружением тестов, а не запуском отдельного headless браузера. Это разделение сохранено явно, чтобы не выдавать один вид проверки за другой.

## Чего ещё нет

Нет backend, настоящих пользователей, регистрации, PostgreSQL, синхронизации и админки. Данные остаются в браузере. Скрытие технической плашки не превращает демо в многопользовательскую платформу. Реальные данные и вход добавляются после реализации серверного плана, проверки доступа и согласования размещения. Для защиты демо не добавлялся фиктивный экран логина.

## Итерация под преддемо

Карта расширена, фильтры перенесены над ней. Новый разбор закупки выбирает назначенного ЛПР комитета среди участников, показывает записанную входящую связь и пробел в оценках. Все выводы открывают основание; при отсутствии данных путь не выдумывается. Модуль src/insights.js проверяет границы клиента, участников и направление связи. Описание полей и демонстрация — в 08_Преддемо.md. Проверено: 28 модульных тестов, 8 общих сценариев через CUA, узкий экран 390 px без переполнения страницы.
